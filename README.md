# dyscyber — учебное бронирование киберклуба

## Тема

Сайт премиального киберклуба **dyscyber**. В общем зале доступны 30 отдельных компьютеров, в двух VIP-комнатах — по 5 компьютеров, в двух Pro-зонах — по 5 компьютеров, также есть отдельная PS5-комната. В VIP и Pro можно забронировать как отдельный компьютер, так и всю комнату/зону целиком.

Pro-зона сделана производительнее VIP-зоны: мониторы 27″ 540 Гц и шумоизоляция. VIP использует RTX 5070 Ti и мониторы 27″ 360 Гц.

## Запуск

Дважды щёлкните **«Запустить сайт.bat»**. Скрипт поднимет локальный сервер на порту 8767 и откроет сайт в браузере. Окно сервера оставьте открытым до окончания работы.

Без `.bat` можно запустить из этой папки:

~~~powershell
python -m http.server 8767
~~~

Затем открыть http://localhost:8767.

## Возможности

- выбор отдельного компьютера или целой VIP-комнаты/Pro-зоны;
- запрет конфликта: бронь комнаты занимает все 5 компьютеров, а занятый компьютер блокирует бронь группы;
- фильтры по локации и почасовой стоимости;
- выбор одной из ближайших пяти дат посещения; прошедшая дата исчезает автоматически после наступления нового дня;
- почасовой тариф на 1–12 часов;
- ночной пакет 22:00–08:00 на фиксированные 10 часов;
- расчёт суммы и проверка значений перед подтверждением;
- раздел «Мои брони», отмена отдельной брони и сброс всех своих броней;
- сохранение в одном ключе `localStorage`, проверка структуры и понятные сообщения об ошибках;
- видимые текстовые статусы «Свободно», «Выбрано» и «Занято», клавиатурное управление и адаптивная верстка.

## Начальная занятость

Для демонстрации заняты: `G-07`, `VIP-1-03`, `PRO-2-04` и PS5-комната. Эти ресурсы нельзя отменить через «Мои брони».

## Ограничение учебной версии

Это учебное демо без регистрации, сервера и оплаты. Полный календарь не используется: сайт показывает только ближайшие пять дат, а бронь с выбранной датой хранится в `localStorage` текущего браузера до отмены пользователем.

## Характеристики

- общий зал: RTX 4070 SUPER, 16 ГБ ОЗУ, монитор 24″ 240 Гц;
- VIP-комната: RTX 5070 Ti, 32 ГБ ОЗУ, монитор 27″ 360 Гц;
- Pro-зона: мощные компьютеры, мониторы 27″ 540 Гц, отдельная шумоизоляция;
- PS5-комната: PlayStation 5 PRO, телевизор 8K, 4 геймпада.

## Источники и инструменты

Внешние изображения и шрифты не используются: визуальная система собрана на HTML и CSS. Код создан с помощью ChatGPT/Codex на ванильных HTML, CSS и JavaScript ES-модулях.

## Полезные промпты и результат

1. «Проверь конфликт брони отдельного компьютера и целой Pro-зоны. Исправь только логику, не меняя оформление». Результат: общая зона блокируется при занятом компьютере, а бронь зоны блокирует все её компьютеры.
2. «Проверь восстановление броней из localStorage, отмену и кнопку сброса своих броней». Результат: данные валидируются, отмена освобождает ресурс, начальная занятость сохраняется.
3. «Проверь адаптивность сайта на ширинах 360, 768 и 1280 пикселей и клавиатурный фокус». Результат: карта переходит в одну колонку, статусы остаются читаемыми, фокус сохраняется после обновления интерфейса.
